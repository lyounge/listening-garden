**ฉบับหลักสำหรับส่งงานและพัฒนาต่อ** — [Mini (โค้ด C ไฟล์เดียว 597 บรรทัด)](GrowGarden/Mini/)

[ฉบับเต็มเดิมสำหรับอ้างอิง](GrowGarden/Main/)

รายละเอียดด้านล่างอธิบายฉบับเต็มเดิม สำหรับวิธีเล่นและอธิบายโค้ด Mini ให้เปิดคู่มือในโฟลเดอร์ Mini


ดับเบิลคลิก **GrowGarden/Main/share/GardenClass.exe** บน Windows พิมพ์เลขเมนูแล้วกด Enter เลือก 1 เพื่อเริ่มเรื่องทันที หรือเลือก 2 เพื่ออ่านวิธีเล่นและสูตรผสมทั้ง 12 สูตรก่อนเปิดร้าน

## ลองเล่าตอนนำเสนอ

“เราเปิดร้านรับฟังเรื่องของลูกค้า พอคุยจบก็ได้ผลึกมาเลี้ยงต้นไม้ คำตอบที่เลือกเปลี่ยนบทสนทนา แต่ลูกค้ายังให้ผลึกเท่าเดิม ตอนเย็นเราต้องตัดสินใจเองว่าจะใช้ผลึกชิ้นไหนตรง ๆ หรือเอาสองชิ้นมาผสมกัน”

เปิด `GrowGarden/Main/share/ListeningGarden.c` แล้วเริ่มอ่านจากฟังก์ชัน `main` ที่ท้ายไฟล์

1. `new_day` สุ่มอากาศกับชุดผลึก แล้วลองปลูกในแผนจำลองเพื่อเก็บเฉลย
2. `meet_customers` ใช้ลูป `for` รับลูกค้า 8 คนต่อจากป้าอิง แต่ละคนมีเรื่อง ผลึก และจำนวนของฝากประจำรอบ
3. `planting` ใช้ลูปรอเลขเมนู ถ้าใช้ตรงก็เลือกจำนวนได้ แต่ละชิ้นเพิ่ม 10 หน่วย ถ้าผสมก็หักสองชิ้น แล้วบวก 10 ให้ส่วนที่เลือก
4. `grow_tree` วาดภาพจุดทีละช่วง ให้กด Enter เพื่อดูต้นไม้เติบโต
5. `morning` แสดงต้นไม้ ผลปลูกและคะแนน แล้วให้ป้าอิงปิดท้าย จากนั้นเลือกดูเฉลยหรือเล่นต่อ

## ตัวอย่างให้ลองวาดบนกระดาษ

คืนแมลง เป้าใบ/ราก/เปลือกคือ 30/20/40 ถ้าใส่ได้ 30/20/30 ให้ผสมผลึกกลุ่มใบกับรากเพื่อเติมเปลือกอีก 10 หน่วย

## เกมสุ่มวันอย่างไร

เกมใช้ `rand()` สุ่มเลข และใช้ `srand(time(NULL))` ตั้งต้นเมื่อเปิดเกม หากเปิดในวินาทีเดียวกันอาจได้ลำดับเดิม วันใช้ตรงมีโอกาส 40% วันผสมหนึ่งครั้ง 40% และวันผสมสามครั้ง 20% ส่วนพายุ แล้ง และแมลง มีโอกาสอย่างละหนึ่งในสาม รอบติดกันจึงเจออากาศเดียวกันได้

เกมกันผลึกให้พอปลูกสมดุลก่อน แล้วสุ่มจัดผลึกอีกส่วนให้ลูกค้า สลับลำดับคนเข้าร้าน และลองทำสูตรให้ได้ Perfect ก่อนเปิดวันนั้น ที่โต๊ะปลูก กด 1 แล้วเลือกใบ ราก หรือเปลือก เกมจะแสดงเฉพาะผลึกตรงกลุ่ม หากต้องการผสมให้กลับโต๊ะปลูก กด 4 เลือกวัตถุดิบสองกลุ่ม แล้วดูผลก่อนยืนยัน กด 2 เพื่อดูต้นไม้ คลังผลึก คู่มือ หรือคืนผลึกทั้งหมด พอพอใจแล้วกด 3 เพื่อปลูก

## ตัวแปรที่ควรรู้

`bag[6]` เก็บจำนวนผลึกดิบแต่ละชนิด ส่วน `value[3]` เก็บหน่วยใบ ราก และเปลือกตามลำดับ สองอาร์เรย์นี้อยู่ใน `Plan` เดียวกัน การส่ง `&plan` ให้ฟังก์ชันคือส่งที่อยู่ของแผน เพื่อให้ฟังก์ชันแก้แผนที่กำลังเล่นได้

ดู `apply` และ `undo` คู่กันใน `GrowGarden/Main/share/ListeningGarden.c` เมื่อใส่ผลึก โปรแกรมจดวัตถุดิบไว้ใน `moves` พอกดย้อน ก็อ่านรายการสุดท้าย คืนวัตถุดิบ แล้วหัก 10 หน่วยออก

บทพูดอยู่ในอาร์เรย์ `stories` และโครงสร้างข้อมูลอยู่ด้านบนของ `GrowGarden/Main/share/ListeningGarden.c` ทั้งทีมแก้เกมในไฟล์เดียวนี้ ส่วน `tests` เป็นชุดตรวจอัตโนมัติ ไม่ต้องส่งไปด้วยเพื่อคอมไพล์เกม

## ทำงานกับเพื่อน

```sh
git switch main
git pull --ff-only
git switch -c feature/planting-menu
```

แก้และคอมไพล์ในเครื่อง ใช้ชื่อไฟล์ทดสอบต่างจาก EXE ที่แจกอยู่ จากนั้น commit เฉพาะไฟล์ที่แก้ push branch และเปิด pull request เข้า main เขียนว่าเปลี่ยนอะไรและลองเล่นทางไหน ให้เพื่อนตรวจ diff และรอ Build and test ผ่านก่อนกด squash merge ถ้าแก้พลาดให้สร้าง PR ย้อน commit ที่รวมไปแล้ว

### สำรองก่อนแก้และส่งงานจาก fork

1. บน GitHub กด Fork เพื่อสร้างสำเนาในบัญชีของเพื่อน แล้ว clone สำเนานั้นลงเครื่อง
2. ก่อนแก้ไฟล์บน Windows ให้รัน `.\scripts\backup.ps1` สคริปต์จะพิมพ์ตำแหน่ง ZIP ที่รวมไฟล์ปัจจุบันและงานที่ยังไม่ได้ commit ควรแตก ZIP ไปโฟลเดอร์ใหม่เมื่อต้องการกู้ บนเครื่องเพื่อนต้องรันเองก่อนแก้
3. สร้าง branch แก้งาน push ขึ้น fork แล้วกด Compare & pull request โดยตั้งปลายทางเป็น `lyounge/listening-garden:main` เจ้าของตรวจและกด Squash and merge หลัง Build and test ผ่าน
4. ทุกครั้งที่ main อัปเดต GitHub Actions จะติด tag `backup/main-...` ให้ commit ก่อนหน้า เปิด Tags เพื่อดูหรือดาวน์โหลดรุ่นนั้น หากต้องย้อนบน main ให้ทำผ่าน revert PR

## การรอดของต้นไม้
ใบ ราก และเปลือกต้องได้รับปุ๋ยอย่างน้อยส่วนละ 10 หน่วย และสุขภาพหลังผ่านอากาศต้องมากกว่า 0 ถ้ายังมีส่วนใดไม่ถึง 10 ต้นไม้จะไม่รอด ส่วนเมล็ดที่ไม่ได้ใส่ปุ๋ยเลยยังแสดงผลว่าไม่ได้เริ่มปลูก
โต๊ะปลูกแสดงเป้าหมายสำหรับผ่านคืนนี้โดยไม่เสียสุขภาพ ซึ่งสูงกว่าเงื่อนไขรอดขั้นต่ำ เป้าจะเปลี่ยนตามค่าใบ ส่วน Perfect ต้องถึงเป้าแต่ละส่วนของคืนนั้น และสุขภาพเต็ม
คู่มือแบ่งเป็นหน้าและข้ามไปเริ่มเล่นได้ ภาพเติบโตข้ามช่วงที่ภาพเหมือนเดิม

## เล่นและนำเสนอ

หลังใส่ปุ๋ยจะกลับไปเลือกส่วนของต้นไม้ได้ทันที กด 0 กลับโต๊ะเพื่อผสมหรือแก้แผน เลือกคืนผลึกทั้งหมดได้หากอยากจัดแผนใหม่
