# สวนรับฟัง

ดับเบิลคลิก **ListeningGarden.exe** บน Windows พิมพ์เลขเมนูแล้วกด Enter เลือก 1 เพื่อเริ่มเรื่องทันที หรือเลือก 2 เพื่ออ่านวิธีเล่นและสูตรผสมทั้ง 12 สูตรก่อนเปิดร้าน

## ลองเล่าตอนนำเสนอ

“เราเปิดร้านรับฟังเรื่องของลูกค้า พอคุยจบก็ได้ผลึกมาเลี้ยงต้นไม้ คำตอบที่เลือกเปลี่ยนบทสนทนา แต่ลูกค้ายังให้ผลึกเท่าเดิม ตอนเย็นเราต้องตัดสินใจเองว่าจะใช้ผลึกชิ้นไหนตรง ๆ หรือเอาสองชิ้นมาผสมกัน”

เปิด `main.c` แล้วเริ่มอ่านจากฟังก์ชัน `main` ที่ท้ายไฟล์

1. `new_day` สุ่มอากาศกับชุดผลึก แล้วลองปลูกในแผนจำลองเพื่อเก็บเฉลย
2. `meet_customers` ใช้ลูป `for` รับลูกค้า 8 คนต่อจากป้าอิง แต่ละคนมีเรื่อง ผลึก และจำนวนของฝากประจำรอบ
3. `planting` ใช้ลูปรอเลขเมนู ถ้าใช้ตรงก็เลือกจำนวนได้ แต่ละชิ้นเพิ่ม 10 หน่วย ถ้าผสมก็หักสองชิ้น แล้วบวก 10 ให้ส่วนที่เลือก
4. `grow_tree` ใน growth.c วาดภาพจุดทีละภาพ เว้นจังหวะประมาณครึ่งวินาที แล้ววาดภาพถัดไปที่เดิม
5. `morning` แสดงต้นไม้และบทส่งท้าย จากนั้นให้ดูคะแนน เฉลย และเลือกเล่นต่อ

## ตัวอย่างให้ลองวาดบนกระดาษ

สมมติคลังมีผลึกกลุ่มใบ 5 ชิ้น ราก 5 ชิ้น เปลือก 2 ชิ้น เป้าคือให้ต้นไม้ได้ 30 หน่วยทั้งสามด้าน

- ใช้ตรง ๆ ตามลำดับ ใบ 3 ชิ้น ราก 3 ชิ้น เปลือก 2 ชิ้น ตอนนี้ต้นไม้มี **30 / 30 / 20**
- หยิบผลึกใบกับรากอย่างละชิ้นมาผสม เช่น สุข + กลัว ได้ “กล้าหาญ” เติมเปลือกอีก 10
- ตอนนี้ต้นไม้มี **30 / 30 / 30** ส่วนคลังยังเหลือใบกับรากอย่างละชิ้น ผ่านได้ทุกสภาพอากาศและได้ Perfect

## เกมสุ่มวันอย่างไร

ทุกครั้งที่จับฉลาก เกมขอเลขจาก Windows ผ่าน `rand_s` และตัดค่าปลายช่วงที่ทำให้บางเลขออกบ่อยกว่าเลขอื่น วันใช้ตรงมีโอกาส 40% วันผสมหนึ่งครั้ง 40% และวันผสมสามครั้ง 20% ส่วนพายุ แล้ง และแมลง มีโอกาสอย่างละหนึ่งในสาม รอบติดกันจึงเจออากาศเดียวกันได้

เกมกันผลึกให้พอปลูกสมดุลก่อน แล้วสุ่มจัดผลึกอีกส่วนให้ลูกค้า สลับลำดับคนเข้าร้าน และลองทำสูตรให้ได้ Perfect ก่อนเปิดวันนั้น ที่โต๊ะปลูก กด 1 แล้วเลือกใบ ราก หรือเปลือก เกมจะแสดงเฉพาะผลึกตรงกลุ่ม หากต้องการผสมให้กลับโต๊ะปลูก กด 4 เลือกวัตถุดิบสองกลุ่ม แล้วดูผลก่อนยืนยัน กด 2 เพื่อดูต้นไม้ คลังผลึก คู่มือ หรือย้อนแผน พอพอใจแล้วกด 3 เพื่อปลูก

## ตัวแปรที่ควรรู้

`bag[6]` เก็บจำนวนผลึกดิบแต่ละชนิด ส่วน `value[3]` เก็บหน่วยใบ ราก และเปลือกตามลำดับ สองอาร์เรย์นี้อยู่ใน `Plan` เดียวกัน การส่ง `&plan` ให้ฟังก์ชันคือส่งที่อยู่ของแผน เพื่อให้ฟังก์ชันแก้แผนที่กำลังเล่นได้

ดู `apply` และ `undo` คู่กันใน `garden.c` เมื่อใส่ผลึก โปรแกรมจดวัตถุดิบไว้ใน `moves` พอกดย้อน ก็อ่านรายการสุดท้าย คืนวัตถุดิบ แล้วหัก 10 หน่วยออก

`stories.c` เก็บบทพูด แก้ข้อความตรงนี้ได้ ส่วน `garden.h` บอกว่าข้อมูลของวัน แผน และผลคะแนนมีอะไรบ้าง

## ไฟล์ส่งงานตามบทเรียน

ใช้ `share/ListeningGarden.c` ส่งไฟล์เดียว โค้ดฉบับนี้แยกจากเกม Windows รุ่นภาพเคลื่อนไหวอัตโนมัติ ด้านบนที่กล่าวถึง `rand_s` เป็นวิธีของเกม Windows ส่วนฉบับส่งงานใช้ `rand()` และกด Enter ดูต้นไม้ทีละช่วง

| ตัวอย่างจากชีท (เลขหน้า PDF) | ลองชี้ให้ดูในเกม |
|---|---|
| 08-String หน้า 14 | `crystal` เป็นอาร์เรย์ข้อความ เรียกชื่อผลึกตามเลขชนิด |
| 09-Pointer หน้า 11 และ 10-Function หน้า 25–26 | `apply(&plan, move)` ส่งที่อยู่ของแผนเข้าไป เมื่อหักผลึก คลังของผู้เล่นจึงเปลี่ยนจริง |
| 10-Function หน้า 10 | `draw(3)` เรียก `rand() % 3` เพื่อเลือกหนึ่งในสามสภาพอากาศ |
| 11-File หน้า 23 | `fgets` อ่านทีละบรรทัด เกมอ่านจากคีย์บอร์ดผ่าน `stdin` |
| 12-Structure หน้า 15–22 | `stories` เก็บลูกค้าหลายคนในอาร์เรย์ของ struct และ `plan->bag` เข้าถึงคลังผ่าน pointer |

เวลาอธิบาย เริ่มที่ `main` ท้ายไฟล์ แล้วตามหนึ่งรอบผ่าน `new_day` → `meet_customers` → `planting` → `grow_tree` → `morning` ภาพต้นไม้และบทพูดเป็นข้อมูลที่อ่านมาแสดง

ส่วนเสริมจากตัวอย่างในชีทคือ `srand((unsigned)time(NULL))` ใน `main` สำหรับตั้งค่าเริ่มต้นให้ `rand()` ตอนเปิดโปรแกรม เวลาในที่นี้นับเป็นวินาที เปิดสองครั้งในวินาทีเดียวกันจึงอาจได้รอบเดียวกัน หากอาจารย์ต้องการให้ใช้เฉพาะฟังก์ชันที่ปรากฏในชีท สามารถตัดบรรทัดนี้และ `#include <time.h>` ออกได้ ลำดับสุ่มจะเริ่มเหมือนเดิมทุกครั้ง

บน Windows เกมเรียก `chcp 65001` ตอนเริ่มเพื่อให้คอนโซลอ่านภาษาไทยและภาพจุดเป็น UTF-8 โดยอัตโนมัติ บรรทัดนี้เป็นส่วนตั้งค่าหน้าจอสำหรับ Windows

ในโฟลเดอร์ที่มีไฟล์ส่งงาน ใช้คำสั่งต่อไปนี้บน Windows

```powershell
gcc -std=c11 ListeningGarden.c -o GardenClass.exe
.\GardenClass.exe
```

## คอมไพล์ด้วย GCC

เปิดเทอร์มินัลในโฟลเดอร์เกมแล้วรัน

```powershell
gcc -std=c11 -Wall -Wextra -O2 main.c garden.c stories.c growth.c -o ListeningGarden.exe
.\ListeningGarden.exe
```

ทดสอบกติกาแยกจากเกมด้วย `gcc -std=c11 test_garden.c garden.c stories.c -o test_garden.exe` แล้วรัน `.\test_garden.exe`

## ทำงานกับเพื่อน

ไฟล์ส่งอาจารย์คือ `share/ListeningGarden.c` ส่วนซอร์สที่รากโฟลเดอร์เป็นเกมอีกรุ่น ก่อนแก้ให้ตกลงกันว่าใครทำเมนู บทพูด หรือกติกา แล้วเริ่มจาก main ล่าสุด

```sh
git switch main
git pull --ff-only
git switch -c feature/planting-menu
```

แก้และคอมไพล์ในเครื่อง ใช้ชื่อไฟล์ทดสอบต่างจาก EXE ที่แจกอยู่ จากนั้น commit เฉพาะไฟล์ที่แก้ push branch และเปิด pull request เข้า main เขียนว่าเปลี่ยนอะไรและลองเล่นทางไหน ให้เพื่อนตรวจ diff และรอ Build and test ผ่านก่อนกด squash merge ถ้าแก้พลาดให้สร้าง PR ย้อน commit ที่รวมไปแล้ว

### สำรองก่อนแก้และส่งงานจาก fork

1. บน GitHub กด Fork เพื่อสร้างสำเนาในบัญชีของเพื่อน แล้ว clone สำเนานั้นลงเครื่อง
2. ก่อนแก้ไฟล์บน Windows ให้รัน `.\scripts\backup.ps1` สคริปต์จะพิมพ์ตำแหน่ง ZIP ที่รวมไฟล์ปัจจุบันและงานที่ยังไม่ได้ commit ควรแตก ZIP ไปโฟลเดอร์ใหม่เมื่อต้องการกู้ บนเครื่องเพื่อนต้องรันเองก่อนแก้
3. สร้าง branch แก้งาน push ขึ้น fork แล้วกด Compare & pull request โดยตั้งปลายทางเป็น `lyounge/listening-garden:main` เจ้าของตรวจและกด Squash and merge หลัง Build and test ผ่าน
4. ทุกครั้งที่ main อัปเดต GitHub Actions จะติด tag `backup/main-...` ให้ commit ก่อนหน้า เปิด Tags เพื่อดูหรือดาวน์โหลดรุ่นนั้น หากต้องย้อนบน main ให้ทำผ่าน revert PR
