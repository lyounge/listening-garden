# Grow a (Feeling) Garden Mini

Mini เป็นไฟล์ C เดียว 619 บรรทัด เก็บบทลูกค้าทั้ง 12 คน ภาพต้นไม้และป้าอิง บทจบ และระบบคะแนนไว้

คอมไพล์จากโฟลเดอร์ mini แล้วเปิดเกม

    gcc -std=c11 -Wall -Wextra -pedantic ListeningGarden-Mini.c -o GardenMini.exe
    .\GardenMini.exe

เปิดร้าน คุยกับลูกค้า 8 คน แล้วอ่านพยากรณ์และเป้าออกดอกบนโต๊ะปลูก
กด 1 ใส่ผลึกตรง กด 2 ผสมผลึกต่างกลุ่ม กด 3 คืนผลึกทั้งหมด หรือกด 4 ยืนยันปลูก ใช้หมายเลขผลึกที่แสดงบนหน้าจอ

new_day สุ่มสภาพอากาศและรายชื่อลูกค้า โดยกำหนดชุดผลึกเป็นสามกลุ่ม กลุ่มที่ขาดมี 2 ชิ้น และอีกสองกลุ่มมีด้านละ 5 ชิ้น จึงจัดปุ๋ยให้ถึงเป้าได้ด้วยการผสมสองชุด เกมใช้ชุดที่เตรียมตามกติกานี้ จึงไม่ต้องหาเฉลยระหว่างเปิดร้าน
add_fertilizer รวมการเลือกผลึกและจำนวนไว้ด้วยกัน ส่วนการคืนผลึกใช้สำเนาแผนก่อนเริ่มปลูก
คู่มือเต็มอยู่ใน [User-Manual.txt](../Main/submission/User-Manual.txt) กติกาอากาศและคะแนนยังใช้อ้างอิงได้ ให้ใช้หมายเลขเมนู Mini ตามหน้าจอ

## โครงสร้างโปรแกรม
เริ่มเกม → สุ่มวัน → คุยกับลูกค้า → จัดปุ๋ย → ยืนยันปลูก → ดูผล → เล่นใหม่หรือออก

- main คุมลำดับของเกม
- new_day สุ่มเหตุการณ์และจัดผลึกให้ลูกค้า
- add_fertilizer หักผลึก แล้วเพิ่มปุ๋ยตามจำนวนที่เลือก
- evaluate คำนวณสุขภาพและผลการปลูก
- morning แสดงต้นไม้ คะแนน และบทป้าอิง

ตัวอย่างตอนเล่น กด 1 ที่โต๊ะปลูก แล้วเลือกผลึกสุข 1 ชิ้นถ้ามีในคลัง จำนวนผลึกสุขจะลดลง 1 และค่าใบเพิ่ม 10 หน่วย

## ซ้อมอธิบายโค้ด
- bag[6] เป็นอาร์เรย์จำนวนผลึก ส่วน value[3] เก็บค่าใบ ราก และเปลือก
- ใน main ส่ง &plan ให้ planting เพื่อส่งที่อยู่ของแผนจริง
- Plan *p ใน planting คือพอยน์เตอร์ที่รับที่อยู่นั้น ส่วน p->bag ใช้เข้าถึงคลังผ่านพอยน์เตอร์ เมื่อเปลี่ยนค่า คลังใน main จึงเปลี่ยนด้วย
- ลองซ้อมแก้สดโดยเปลี่ยนข้อความชื่อเกมใน main แล้วคอมไพล์ใหม่ ชี้ให้เห็นว่าข้อความที่แก้ขึ้นตรงหน้าแรก

ลำดับสาธิต: อธิบายโจทย์ → ชี้ข้อมูลใน Plan → ทดลองกรอกเลขผิดและจัดปุ๋ย → ดูผลปลูก → บอกข้อจำกัดว่าทุกรอบต้องผสมสองชุดเพื่อออกดอก

หน้าแรกกด 2 อ่านวิธีเล่น แล้วกด Enter กลับมาเลือกเริ่มเกมได้

ที่โต๊ะปลูก กด 5 ดูสูตรผสมทั้ง 12 คู่ได้โดยไม่ใช้ผลึก
